The one line a smart fridge texts its owner at 3am, for make.fun's "The 3AM Fridge Text" bounty. `main.py` writes the entry to `/output/entry.txt`.

The entry:

> 3am. The leftovers have unionised and want a microwave. I said you're asleep. They saw the light.

## Run it

```sh
python3 main.py
```
